# Week 1 — Learning Notes

- REST maps HTTP methods to actions on resources; the URL names the resource, the method names the action.
- Status codes communicate outcome clearly — `2xx` success, `4xx` client error, `5xx` server error.
- Statelessness means every request must carry its own auth; the server keeps no session memory.
- JSON is the default request/response format, sent with `Content-Type: application/json`.
- SQL basics: tables hold rows, relations link tables via foreign keys, indexes speed up lookups, migrations version schema changes.
- Git feature-branch flow keeps `main` clean; changes are reviewed via pull requests before merging.
- AI is a productivity tool for understanding, boilerplate, and debugging — but the developer stays responsible for reviewing and testing the output.
