# AI Prompts Used (learning & code understanding)

Three prompts I actually used this week, with what each was for.

## Prompt 1 — Understand a new stack quickly
> "I'm an experienced developer new to FastAPI. Give me a 10-minute mental model of how a FastAPI project is structured: where routing, models/schemas, validation, and error handling live. Show a minimal working example with one GET and one POST endpoint."

**Used for:** getting an accurate mental model of FastAPI fast instead of reading scattered docs.

## Prompt 2 — Explain existing code
> "Explain this code block line by line, then summarize what it does in two sentences. Point out anything that could break or any missing error handling: [paste code]."

**Used for:** understanding code before relying on it, and spotting weak error handling.

## Prompt 3 — Generate a focused learning plan
> "I have 5 days and prior backend experience. Build me a day-by-day plan to learn enough FastAPI to create a validated /items CRUD API with SQLite. List the exact concepts per day and one small exercise each."

**Used for:** turning a vague goal into a concrete day-by-day plan.

---

**Safe AI usage note:** never paste secrets, credentials, tokens, or production data into AI tools. Always read, understand, and test generated code before using it.
